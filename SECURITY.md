# Seguridad

Gracias por tomarse el tiempo de reportar un problema de seguridad. Esta página explica cómo hacerlo
y qué ocurre después.

## Cómo reportar

Escriba a **seguridad@habil.mx** con el asunto «Reporte de seguridad».

Ayuda incluir, en la medida de lo posible:

- qué repositorio o dirección se ve afectada,
- los pasos para reproducirlo,
- qué se puede llegar a hacer con el problema,
- y cómo prefiere que lo acreditemos, si quiere que lo hagamos.

**No abra un issue público** para reportar una vulnerabilidad: un issue es visible para cualquiera
desde el primer minuto, y eso expone a quien todavía no ha podido corregirla.

## Qué ocurre después

- **Acusamos recibo** de su reporte.
- Lo revisamos y le decimos **si lo consideramos una vulnerabilidad y por qué**, aunque la conclusión
  sea que no lo es.
- Le mantenemos **informado hasta que el caso se cierra**.

## Divulgación responsable

Le pedimos que **no haga público el problema hasta que esté corregido**, para que quien lo use no
quede expuesto mientras tanto. Trabajamos con usted en el momento de publicarlo.

## Alcance

Esta página cubre los repositorios públicos de esta organización. Si el problema afecta a
**habil.mx** o a un sistema operado por Hábil, use el mismo correo y dígalo en el asunto.

# Security

Thank you for taking the time to report a security issue. This page explains how to do it and what
happens next.

## How to report

Email **security@habil.mx** with the subject «Security report».

Where possible, please include which repository or address is affected, the steps to reproduce it,
what the issue makes possible, and how you would like to be credited, if at all.

**Please do not open a public issue** to report a vulnerability: an issue is visible to everyone from
the first minute, and that exposes the people who have not been able to fix it yet.

## What happens next

- We **acknowledge receipt** of your report.
- We review it and tell you **whether we consider it a vulnerability and why**, even when the answer
  is that it is not.
- We **keep you informed until the case is closed**.

## Responsible disclosure

We ask that you **not make the issue public until it has been fixed**, so that people using it are
not left exposed in the meantime. We will work with you on when to publish.

## Scope

This page covers the public repositories of this organization. If the issue affects **habil.mx** or a
system operated by Hábil, use the same address and say so in the subject line.
